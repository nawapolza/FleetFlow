HENG CHAROEN PHUETPHON FUEL SYSTEM
Release: V48.0.0 — LITERS TO DISTANCE

PACKAGE CONTENT
- Backend source code
- Frontend source code
- Database notes
- Render configuration
- Git repository metadata from the supplied project
- V48 fuel-distance documentation

PRIMARY V48 FEATURES
- Set average fuel efficiency per vehicle in km/liter
- Auto-fill the vehicle rate after selecting a plate number
- Calculate estimated distance immediately from liters × km/liter
- Persist a manually entered rate back to that vehicle for future entries
- Keep estimated distance separate from optional actual distance
- Show estimated distance, actual distance, expected rate, and actual efficiency on receipt cards
- Backward-compatible MongoDB fields; no destructive database migration required

FORMULA EXAMPLE
- 223 liters × 3.00 km/liter = 669.00 km estimated distance
