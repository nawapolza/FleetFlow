HENG CHAROEN PHUETPHON FUEL SYSTEM — FULL SOURCE V49.0.0
========================================================

รุ่น: 49.0.0
ธีม: Professional Blue & White

สิ่งที่เพิ่ม/ปรับปรุงหลัก
----------------------
1. คำนวณระยะทางอัตโนมัติจาก "จำนวนลิตร × อัตราประจำรถ"
2. หน้าบันทึกงานไม่ต้องกรอกอัตราวิ่งรถซ้ำในแต่ละเที่ยว
3. ตั้งอัตราแยกต่อรถได้ครั้งเดียวที่เมนู "รถและคนขับ"
4. มีปุ่มลัด 2.90 / 3.00 / 3.20 กม./ลิตร และกรอกค่าอื่นเองได้
5. ตัวอย่าง: 208 ลิตร × 2.90 กม./ลิตร = 603.20 กม.
6. Backend ยึดอัตราที่บันทึกกับทะเบียนรถเป็นแหล่งข้อมูลหลัก
7. เพิ่มโลโก้จริงของ "เฮงเจริญพืชผล" ในหน้าระบบและไอคอนแอป
8. ปรับ UX/UI ทั้งระบบเป็นน้ำเงิน-ขาว ปุ่มและข้อมูลสำคัญชัดเจนขึ้น

โครงสร้างแพ็กเกจ
----------------
- frontend/       React + Vite + Tailwind CSS
- backend/        Node.js + Express + MongoDB
- database/       ไฟล์ฐานข้อมูล/ข้อมูลประกอบเดิม
- render.yaml     ตั้งค่าสำหรับ Render
- README.md       วิธีติดตั้งและใช้งาน
- BLUE_AUTO_DISTANCE_V49.md รายละเอียดฟังก์ชัน V49
